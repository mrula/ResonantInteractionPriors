# ResonantInteractionPriors
This repository contains code written as part of my Carlsberg Foundation Postdoctoral Fellowship in the project "Resonant mode-particle interaction priors for energetic particle phase-space tomography".

The `test_3D_tomo.py` script computes a 3D reconstruction of an energetic-particle distribution function in the TCV tokamak from synthetic data. It does so using a newly developed prior taking into account resonant wave-particle interactions computed using the so-called kick model [M. Podestà et al PPCF **56**, 2014, 055003].

However, the data used for these scripts are located in non-public repositories.
